# Max Parser

Парсер для платформы MaxChat, построенный на базе Crawlee и Playwright.

## Требования

- Python 3.11+
- [uv](https://github.com/astral-sh/uv) (рекомендуется)

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости:
   ```bash
   uv sync
   ```
3. Установите браузеры Playwright:
   ```bash
   uv run playwright install chromium
   ```

## Настройка

Настройки находятся в `src/config.py`. Вы можете переопределить их через переменные окружения или `.env` файл:

- `HEADLESS`: Режим работы браузера (по умолчанию `True`). Для прохождения 2FA установите `False`.
- `BASE_URL`: Базовый URL платформы.

## Запуск

```bash
uv run python -m src.main
```

**Важно:** При первом запуске предусмотрена пауза 60 секунд для ручного ввода данных 2FA, если это необходимо. Для этого убедитесь, что `HEADLESS=False`.
